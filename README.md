# Adrak for Windows

Adrak is a learning app for Windows 10 and 11: interactive lessons with maps, code, diagrams, math and quizzes, a
library of ready-made lessons, and an AI Agent that writes new lessons, practice and exams for what you are learning.

## Download

Get **AdrakApp-win-Setup.exe** from the [latest release](https://github.com/snwaf929-cpu/adrak-releases/releases/latest)
and run it. It installs Adrak for your Windows account, with no administrator rights needed, and keeps it up to date:
Adrak looks here for new versions and offers to restart into them.

The first time, Windows may say "Windows protected your PC", because the installer is not code-signed yet. Choose
**More info**, then **Run anyway**.

## Your learning

What you learn stays on your PC, in `%LocalAppData%\Adrak`. In Settings you can link a GitHub repository of your own to
keep it in sync between your computers. Uninstalling Adrak leaves it in place.

This repository holds only the installer and its updates.
